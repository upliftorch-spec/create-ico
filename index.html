常見問題

什麼是 ICO 格式？

ICO（Icon）是 Windows 系統使用的圖示格式，副檔名為 .ico。它可以包含多種尺寸的圖片，讓作業系統根據顯示環境自動選擇適合的尺寸。ICO 格式也廣泛用於網頁的 Favicon（瀏覽器分頁圖示）。

ICO 格式有哪些用途？

ICO 格式主要用於以下場景：網頁 Favicon（顯示在瀏覽器分頁和書籤列）、Windows 桌面圖示和應用程式圖示、Windows 資料夾自訂圖示，以及可執行檔（.exe）的程式圖示。

支援哪些圖片格式上傳？

本工具支援所有瀏覽器可顯示的圖片格式，包括 PNG、JPG/JPEG、GIF、BMP、WebP、SVG 等。建議使用 PNG 格式作為來源圖片，可獲得最佳的透明背景效果。

圖片最大可以是多少尺寸？

本工具支援最大 10MB 的圖片檔案，圖片解析度沒有嚴格限制。不過建議使用 256×256 或以上的高解析度圖片，這樣縮小後的 ICO 圖示也能保持清晰的細節。

這個工具是免費的嗎？有使用次數限制嗎？

完全免費使用，沒有任何使用次數限制，也不需要註冊帳號或提供電子郵件。您可以無限次使用本工具轉換圖片。

我的圖片會被上傳到伺服器嗎？安全嗎？

不會。本工具的所有圖片處理都在您的瀏覽器（客戶端）中進行，利用 HTML5 Canvas API 直接在裝置上完成轉換。您的圖片不會被上傳到任何伺服器，關閉分頁後所有資料立即消失。

如何製作包含多個尺寸的 ICO 檔案？

目前本工具每次可下載單一尺寸的 ICO 檔案。如需包含多個尺寸的 ICO 檔案（標準 Favicon 通常包含 16×16 和 32×32），您可以分別下載再使用 ICO 合併工具進行組合，或使用 16×32 最常用的尺寸即可滿足大多數需求。

轉換後的圖片會失真嗎？

轉換過程使用高品質的雙線性插值縮放算法，可在縮小圖片時保留最多的細節。為確保最佳效果，建議使用解析度至少 256×256 的原始圖片，避免將低解析度圖片放大後再縮小。
